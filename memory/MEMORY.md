# Permanent Memory Index (`memory/MEMORY.md`)

This file is the single index for permanent, cross-cutting memories, entity profiles, preferences, and durable facts that do not belong exclusively to a single topic folder.

---

## Memory Guidelines

1. **Keep it Lean:** Summary entries here point to slug-named detail files (`memory/<slug>.md`).
2. **Point-in-Time Observations:** Memory files record dated facts observed at a specific time. Before asserting a memory as fact, verify against live state.
3. **No Duplicates:** Search this index before writing a new memory file to avoid writing duplicate entries.
