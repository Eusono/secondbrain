# Ritual: Video & Media Mining (`skills/rituals/watch.md`)

This ritual extracts technical notes, key takeaways, code architecture, and action items from technical talks, video presentations, or podcasts.

---

## Workflow

1. **Fetch Transcript / Audio Log:** Obtain the transcript or text summary of the presentation.
2. **Extract Key Technical Concepts:**
   * Architectural decisions and trade-offs.
   * Tool recommendations and workflow improvements.
   * Common pitfalls to avoid.
3. **Format & Store:** Save a clean summary document in `lab/` or `work/ideas/`.
